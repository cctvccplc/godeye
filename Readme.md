# 🗺️ Google Maps Pro - Web Console

A feature-rich, lightweight, and mobile-friendly web map viewer built using **Leaflet.js**, **OpenStreetMap**, and **ESRI Satellite Imagery**. Designed to mimic official Google Maps functionality directly inside a web browser or custom mobile application wrapper.

---

## ✨ Features

* **🗺️ Multiple Map Layers:** Switch seamlessly between *Default Street*, *Satellite Imagery*, *Terrain*, and *3D/High-Angle View*.
* **📍 Live GPS Tracker:** Detects your precise live geolocation with accuracy metrics and pins your position with a marker.
* **🔍 Auto-Suggest Search Bar:** Real-time location search drop-down suggestions powered by Nominatim API.
* **📏 Live Distance Calculator:** Automatically measures and displays the exact distance (in meters or kilometers) between your current GPS location and the searched target location, complete with a visual dashed route line.
* **📱 Mobile Optimized:** Designed with a clean, modern UI (HUD panels, floating action buttons, and responsive layout) specifically tailored for mobile and web-view apps.

---

## 🚀 Quick Setup & Usage

1. Clone or download this repository.
2. Open the `tracker.html` file in any modern web browser or host it via GitHub Pages / InfinityFree.
3. Allow location permissions on your device to use the **Live GPS** and **Distance Calculator** features.
